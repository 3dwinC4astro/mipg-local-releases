# MIPG Local · Instaladores

Este repositorio solo contiene los instaladores publicados de **MIPG Local** para Windows.
El código fuente es privado.

- Descarga la última versión en [Releases](../../releases/latest): `MIPG-Local-X.Y.Z-Setup.exe`.
- Las instalaciones existentes detectan las versiones nuevas por sí mismas y piden confirmación antes de instalarlas.
- Para verificar un instalador descargado, compara su SHA-256 con `SHA256SUMS.txt` del mismo Release:
  `Get-FileHash -Algorithm SHA256 .\MIPG-Local-X.Y.Z-Setup.exe`

Los Releases se publican automáticamente; no subas archivos a mano.
